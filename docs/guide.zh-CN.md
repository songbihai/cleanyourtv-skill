# CleanYourTV Skill 中文使用教程

[返回英文 README](../README.md) · [技能入口](../SKILL.md) · [版本下载](https://github.com/songbihai/cleanyourtv-skill/releases)

用自然语言告诉 AI 助手你的目标，让它帮你审查电视上的预装应用、整理清理方案，或配置更简洁的桌面。你先看清计划和恢复步骤，再决定是否执行。

这个 Skill 将 [cleanyourtv](https://github.com/Gathin23/cleanyourtv) 的工作流程整理为可重复使用的技能：**使用更方便，执行更有约束**。它增加设备身份核对、关键功能保护、逐项变更、异常停止和恢复记录。它是一套给助手使用的指令与离线工具，不是装在电视上的遥控器或一键清理 App；设备操作仍取决于助手的工具、权限和你的确认。

## 1. 先确认适用范围

适用于你拥有或获准管理的 **Android TV / Google TV**。可以先做只读审查；实际修改要求确认硬件身份、当前为未受管理的设备所有者用户 0，并有可用的现场恢复方式。安装或更新桌面还要求确认设备只有一个用户。

Samsung Tizen、LG webOS、Fire OS，以及受单位管理或处于其他用户会话的设备，不使用本教程的修改流程。不要仅凭电视品牌判断系统；同一品牌可能使用不同系统和固件。

本 Skill 会保留原有桌面、所有 Home 候选程序、设置向导、系统更新、网络、输入与遥控、键盘、DRM 等关键功能。用途不明或依赖不清楚的应用保持原状。它不会为了更换桌面而停用系统桌面或设置向导。

## 2. 准备完整技能目录

1. 打开[仓库主页](https://github.com/songbihai/cleanyourtv-skill)，通过 **Code → Download ZIP** 下载当前源码，解压后将包含 `SKILL.md` 的目录命名为 `cleanyourtv-skill`。`main` 上的中文版教程也可以直接在线阅读。
2. 如果希望使用固定版本，打开 **Releases**，下载指定版本的技能 ZIP 和相邻 `.sha256` 文件，核对 SHA-256 后解压。较早的版本包可能不包含本教程，请以对应版本的技能和引用文件为准。
3. 保留整个目录。不要只复制 `SKILL.md`，也不要将上游项目、电视日志或 ADB 密钥混进技能目录。

主要文件的作用：

| 文件 / 目录 | 用途 |
| --- | --- |
| `SKILL.md` | 助手的任务入口和共同执行边界 |
| `references/` | 连接、清理、桌面、网络和恢复的详细流程 |
| `scripts/plan_guard.py` | 离线检查应用清理计划，生成命令参数但不执行 |
| `docs/compatibility.md` | 不同助手的安装位置、调用方式和工具不足时的处理 |
| `docs/guide.zh-CN.md` | 本篇中文教程 |

### 在 AI 助手中使用

支持原生 Agent Skills 的客户端，按其文档安装**完整目录**，再调用 `cleanyourtv-skill`。具体路径和调用语法见[客户端兼容性指南](compatibility.md)，旧版客户端或云端会话的位置可能不同。

不支持原生 Skills、但可以读取文件的助手，也可以使用：提供 `SKILL.md`，并让助手按任务读取它引用的文件。如果上传文件，确认所需引用也能读取。没有终端或设备权限时，让它只做审查和计划；不要让它声称已经连接或修改了电视。

安装或激活技能不等于允许修改电视，也不需要给助手开放全部终端权限。

## 3. 第一次使用：只审查，不修改

实际连接需要 Android SDK Platform Tools（ADB）、电视端的调试授权，以及在电视旁可用的实体遥控器。按照[连接流程](../references/device-workflow.md)和[Android 官方 ADB 文档](https://developer.android.com/tools/adb)准备工具与连接；菜单名称和无线调试能力随系统版本而异。无线配对端口与连接端口可能不同，只使用这台电视实际显示或由你确认的地址。

先准备这些信息，在你与助手的私密会话中提供即可，不要贴到公开 Issue：

- 电视的型号、系统版本和固件版本；不知道的字段让助手继续核对。
- 你明确确认的 ADB 设备序列号或连接端点，不要让助手扫描整个局域网寻找电视。
- 必须保留的功能与 App，例如投屏、语音、HDMI、直播和常用流媒体。
- 你是否在电视旁、能否使用实体遥控器打开系统设置，以及发生问题后的恢复方式。

复制下面的请求，把括号中的内容换成自己的信息：

```text
请使用 cleanyourtv-skill，用中文协助我。
我想先审查自己的 Android TV / Google TV，不做任何修改。
电视型号：[型号]；系统和固件：[版本，未知部分请核对]。
我确认的 ADB 目标：[设备序列号或连接端点]。
必须保留：[常用 App、投屏、语音、HDMI 等]。
我在电视旁，可以操作实体遥控器。
请先读取技能及连接流程，核对硬件身份、用户和管理状态，
再解释哪些应用适合进一步审查；暂时不要安装、停用或改设置。
```

如果不在电视旁，明确告诉助手；不要照抄“我在电视旁”。身份无法确认、恢复方式不可用或工具受限时，保持只读审查或计划模式。

## 4. 清理应用：先看具体计划，再批准

审查之后，可以继续说：

```text
请基于这台电视当前的证据，准备一个最小的应用清理计划。
说明每个应用的作用、建议停用的理由、可能失去的功能、
原来的启用状态、对应恢复操作，以及每一步如何检查。
每份计划最多五个应用，不清楚的先跳过。
请运行离线计划检查器，把最终计划给我看，先不要执行。
```

确认计划时，重点看：

| 需要看清的内容 | 为什么要看 |
| --- | --- |
| 目标电视及硬件身份 | IP 地址相同，不一定还是同一台电视 |
| 应用包名、作用和当前固件证据 | 其他型号的成功清单不能直接套用 |
| 预期损失与保留功能 | “预装”不代表可以放心停用 |
| 修改前的准确状态和对应恢复操作 | 恢复不能简单地把所有应用重新启用 |
| 检查与停止条件 | 超时或没有报错，不代表执行成功 |

计划符合你的意图后，再明确授权。例如，仅当你已看过具体计划和恢复内容时回复：

```text
我确认上面展示的具体计划和目标电视。
只执行计划中列出的应用变更，每次处理一个，检查通过后再继续。
如果检查失败，我同意按这份计划中记录的准确恢复操作
恢复本次已变更的状态，然后停止并报告结果。
不要增加应用、安装软件、改网络或启用无障碍服务。
```

目标、固件、应用清单、影响或恢复方式变化时，需要重新审阅。不要仅回复“全部优化”就让助手自行扩展范围。

每次变更后，结合助手的状态读取，在电视上检查桌面与设置、方向键与返回键、实体遥控和输入切换、网络，以及你实际使用的播放、投屏和语音功能。截图无法证明声音、DRM 播放和实体按键都正常。出现异常，立即停止后续变更。

## 5. 想要更简洁的桌面

清理应用和安装桌面是两件事，分别确认。可以从只在电脑上构建开始：

```text
请使用 cleanyourtv-skill，按已审查并固定的上游提交，
在电脑上准备一个更简洁的电视桌面。
我想保留的常用 App 和顺序是：[列表]。
请先读取桌面流程，说明构建工具、下载依赖和签名情况，
展示构建结果以及安装、切换 Home 和恢复计划。
现在不要安装到电视，也不要修改默认桌面。
```

随后再分别决定是否安装、更新或切换 Home。保留原有桌面并先测试新桌面；固件不允许正常切换时停止，不通过停用系统桌面、绕过签名校验或卸载已有应用来强行切换。上游构建使用调试签名，产物用于个人侧载时应核对来源、权限和证书。

主题修改还要记录原来的文件和桌面设置选择。只把旧主题文件传回去，不一定能还原布局和动效设置。不要让助手直接运行捆绑了安装、权限、桌面切换或无障碍设置修改的上游快捷脚本。详细要求见[桌面流程](../references/launcher.md)。

## 6. 新版可选功能怎么用

| 功能 | 推荐请求与注意事项 |
| --- | --- |
| 模块卡片（Module cards） | 让助手解释某一张卡片的来源和身份，再逐张决定。不熟悉的选择 **Keep hidden**；确认后才选择 **Show card**。隐藏卡片不需要卸载 App。 |
| 布局、动效与主题 | 说明你想调整的选项，让助手先记录当前选择和恢复方法。保留与本次目标无关的设置。 |
| 遥控按键辅助 | 先说明哪个实体按键不符合预期。无障碍服务需要单独确认，并保留其他服务；最终测试真实遥控器。 |
| Private DNS | 单独提出需求，并自己选择服务商与准确主机名。要记录原状态，并有人能在电视旁恢复网络；它不能屏蔽所有广告。 |
| 远程私有连接 | 只使用你已配置并授权的私有路由，先确认目标与现场恢复条件。不把 ADB 暴露到公网，也不自动创建 VPN、路由或共享访问。 |

普通清理任务不会自动启用这些功能。网络选项的具体流程见[可选网络功能](../references/network-extras.md)。

## 7. 出现问题时怎么处理

告诉助手发生了什么，要求它读取[恢复流程](../references/recovery.md)，使用本次会话保存的原始状态与操作记录。可以复制：

```text
请停止所有后续变更。刚才出现的问题是：[具体表现]。
请读取恢复流程和本次会话记录，重新确认设备身份及当前状态，
只处理已经批准的本次变更的准确恢复，不要批量重新启用应用，
也不要重启、恢复出厂设置或尝试新的优化。
如果连接断开，请说明现场能采取的恢复步骤和仍待解决的事项。
```

如果还没有批准具体恢复操作，先审阅后再授权。连接断开时不要连续重试写入、反复强制断电或修改电脑防火墙。由现场人员用实体遥控器和设置按预先准备的路径恢复；必要时使用厂商针对该型号的支持方案。只有功能再次检查正常，才能把恢复标记为完成。

结束前，让助手汇总本次修改、跳过项、恢复结果，以及留在本地的记录位置。记录应在技能仓库之外的私密目录；保留好恢复资料，待检查与恢复完成后关闭不再需要的调试并撤销临时配对。

## 8. 没有电视，也可以先熟悉流程

在解压后的**技能根目录**使用 Python 3.10 或更新版本运行：

```text
python3 scripts/plan_guard.py --snapshot examples/snapshot.synthetic.json --plan examples/plan.synthetic.json --demo
```

如果你的 Windows 环境使用 `python` 启动 Python 3，请把 `python3` 换成 `python`。这个演示只读取合成示例，不连接电视、不执行 ADB，也不输出可执行的设备命令。示例不能用作真实电视的证据。

应用计划检查器只校验其支持的应用计划格式；通过检查不等于允许执行，也不代表它已检查桌面安装、主题、权限或 DNS 操作。

## 9. 常见问题

**教程是中文，Skill 是英文，会影响使用吗？**

可以直接用中文提需求、看解释和确认计划。英文 `SKILL.md` 与引用文件提供共同执行规则，本教程帮助你使用它们，不替代或放宽这些规则。包名、设备标识、选项值和命令不要翻译。

**必须购买 App 或订阅某个 AI 服务吗？**

Skill 本身不绑定模型厂商、付费 API 或外部遥控 App。具体助手是否收费、能否访问终端和文件，由你使用的平台决定。

**README 里的 TVRemoteX 是必需的吗？**

不是。它是维护者的可选遥控 App 展示，与本 Skill 独立。需要时可查看 [TVRemoteX 的 App Store 页面](https://apps.apple.com/us/app/tvremotex-universal-tv-remote/id6755671893)，支持情况和购买选项以该 App 页面为准。

**比直接复制上游命令方便在哪里？**

你只需描述目标，助手就能按需要读取相关流程、整理证据和恢复计划。设备核对、关键功能保护和异常停止规则让执行过程更受控。不要把这些规则当作任何型号都可以套用的安全包清单。

**能提供“一键停用全部推荐包”的命令吗？**

本教程采用逐台核对、逐项确认的方式。直接让助手先审查这台电视，再给出最小计划，会更符合这个 Skill 的用途。
